# TestWeightBecomeSimulator

## 목적
- 현재 체중, 나이, 키를 입력하면 해당 체중이 어떻게 줄어드는지에 대한 시뮬레이터를 제공합니다.
- 시뮬레이터는 체중을 숫자로 표시하며, 5등신 사람 모양의 그림으로 시각화합니다. 체중이 높을수록 머리 쪽에 표시됩니다.
- 체중 범위는 30kg ~ 150kg이며, 30kg 이하는 30kg, 150kg 이상은 150kg으로 고정합니다.
- 좌우 스크롤바를 통해 기간을 설정할 수 있으며, 스크롤바가 움직이면 해당 기간 동안 체중이 얼마나 줄어드는지를 계산하여 표시합니다.
- 추가 입력 사항:
  - 매일 칼로리 섭취량을 입력하여 기간에 따른 체중 변화를 계산합니다.
  - 운동 시간을 입력하고, 강도를 1단계(쉬움) ~ 5단계(어려움)으로 설정하여 체중 변화를 확인합니다.
- 계산식은 인터넷 자료를 참고하여 간단하게 구현하며, 입력한 내용에 따라 체중이 어떻게 변화되는지를 시각적으로 확인할 수 있는 시뮬레이터를 목표로 합니다.

## 기능
- **화면 2분할**:
  - **좌측 화면**: 사람 모양 크기 크게 표시 (체중에서 운동강도까지의 크기). 발바닥을 30kg, 머리끝을 150kg로 설정. 입력된 체중을 검정 점선 가로선으로 표시하며, 좌측과 우측에 체중 값 표시. 사람 모양 아래에 좌우 스크롤바로 기간 설정 (최대 700일). 스크롤 이동 시 계산된 체중 표시. 예측 체중이 현재 체중보다 높으면 파란색 점선, 낮으면 빨간색 점선으로 표시하며, 우측에 변경된 체중 표시.
  - **우측 화면**: 입력 내용. 체중, 나이, 키, 성별, 매일 칼로리, 운동 시간, 운동 강도에 대해 텍스트 입력과 좌우 스크롤바 제공. 스크롤바 좌측 끝은 낮은 수치, 우측 끝은 높은 수치로 설정되며, 이동 시 텍스트 값 변화.
- **기간 설정**: 좌측 스크롤바로 기간(일 단위, 최대 700일) 설정, 우측 입력에 따라 계산된 결과를 표시.
- **계산**: 칼로리 결핍과 운동 강도를 기반으로 체중 변화 계산.
- **시각화**: 숫자 표시와 크게 확대된 사람 그림, 점선으로 체중 위치 표시. 좌우 점선에 현재 체중과 예상 체중을 함께 보여줍니다. 점선은 사람 이미지 높이 800px 범위 내에서 이동합니다 (30kg: 하단, 150kg: 상단).
- **이미지 크기**: 사람 이미지는 고정된 크기 600x800으로 표시됩니다. 체중 변화에 따라 사람 이미지는 변하지 않습니다.
- **점선 이동**: 체중 변화에 따라 이동하는 것은 점선만이며, 좌우 기간 스크롤 값에 따라 점선 위치가 달라집니다. 점선은 이미지 크기 800px 내에서만 움직입니다.
- **초기화 버튼**: 좌우 스크롤 아래 초기화 버튼을 눌러 모든 수치를 기본값으로 리셋할 수 있습니다 (체중 65kg, 나이 25세, 키 170cm, 칼로리 0, 운동시간 1시간, 강도 1, 기간 0일, 성별 남성).
- **경고 메시지**: 입력 체중이 30kg 이하 또는 150kg 이상일 때 조치 안내 메시지를 표시합니다.

## 계산식 (간단 버전)
- 기본 대사율(BMR): Mifflin-St Jeor 공식 사용.
  - 남성: BMR = 10 * 체중 + 6.25 * 키 - 5 * 나이 + 5
  - 여성: BMR = 10 * 체중 + 6.25 * 키 - 5 * 나이 - 161
- 총 일일 에너지 소비(TDEE): BMR * 활동 계수 (기본 1.2).
- 칼로리 효과: 섭취 칼로리가 TDEE보다 높으면 체중이 증가하고, 낮으면 체중이 감소합니다.
- 근력 운동 효과: 운동 강도 1은 주당 약 5%, 5는 주당 약 15% 체중 감소 효과.
- 나이가 1살씩 늘어날수록 운동 효과가 설정된 수치에서 1%씩 감소합니다.
  - 40세 이상이면 추가 -1%
  - 50세 이상이면 추가 -2%
  - 60세 이상이면 추가 -5%
- 운동 강도가 낮을수록 체중 감량 속도가 10%씩 감소됩니다.
- 운동 시간 1시간/일을 기준으로 감량이 적용하며, 기간에 따라 비례 계산합니다.
- 최종 체중: 현재 체중 + 칼로리 기반 변화 - 운동 기반 감량.

## 사용 방법
1. 브라우저에서 index.html 열기.
2. 입력 값 입력.
3. 기간 스크롤바 조정하여 체중 변화 확인.
